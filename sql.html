E-commerce Sales Funnel Analysis

In this project, a full sales funnel was analyzed for an e-commerce platform — tracking user behavior across five stages from page view to purchase, calculating step-by-step and overall conversion rates, evaluating marketing channel performance, and measuring time-to-conversion for each buyer.

+ E-commerce Sales Funnel Analysis +

Objective

This SQL project analyzes the full purchase journey of users on an e-commerce platform. Using a single event-log table user_events, the project identifies how many users reach each funnel stage, where they drop off, which marketing channels drive the most revenue, and how long buyers take to convert.

Part 1: Defining Funnel Stages & Counting Users

WITH funnel_stages AS (
  SELECT
    user_id,
    MAX(CASE WHEN event_type = 'page_view'      THEN 1 ELSE 0 END) AS reached_page_view,
    MAX(CASE WHEN event_type = 'add_to_cart'    THEN 1 ELSE 0 END) AS reached_add_to_cart,
    MAX(CASE WHEN event_type = 'checkout_start' THEN 1 ELSE 0 END) AS reached_checkout,
    MAX(CASE WHEN event_type = 'payment_info'   THEN 1 ELSE 0 END) AS reached_payment,
    MAX(CASE WHEN event_type = 'purchase'       THEN 1 ELSE 0 END) AS reached_purchase
  FROM user_events
  GROUP BY user_id
)

Each user is flagged (0 or 1) for whether they reached each of the five funnel stages: page_view → add_to_cart → checkout_start → payment_info → purchase. Results are aggregated to show user count at each stage, the percentage relative to the top of the funnel, and the number of users dropped at each step.

Part 2: Calculating Conversion Rates

ROUND(100.0 * cnt_checkout / cnt_add_to_cart, 1) AS step_conversion_rate,
ROUND(100.0 * cnt_checkout / cnt_page_view,   1) AS overall_conversion_rate

Two conversion metrics are added to the funnel report: step conversion rate (how many users proceeded from the previous step) and overall conversion rate (how many users from the top of the funnel reached this stage). This helps pinpoint the exact bottleneck in the purchase journey.

Part 3: Marketing Channel Analysis

ROUND(100.0 * users_purchased / NULLIF(users_page_view, 0), 1) AS conversion_rate,
ROUND(total_revenue / NULLIF(total_users, 0), 2)               AS revenue_per_user

Each traffic source (e.g. Organic, Paid, Social, Email) is evaluated across multiple dimensions: total users and events, funnel progression per channel, conversion rate from view to purchase, total revenue, average order value, and revenue per user — enabling direct ROI comparison across channels.

Part 4: Time-to-Conversion Analysis

DATEDIFF(MINUTE, time_page_view, time_add_to_cart) AS mins_view_to_cart,
DATEDIFF(MINUTE, time_page_view, time_purchase)    AS total_mins_to_purchase

For every user who completed a purchase, the time (in minutes) between each funnel step is calculated. A summary layer then outputs system-wide averages, as well as the fastest and slowest conversion times — providing insight into buyer urgency and friction points.

Conclusion

This project demonstrates a complete end-to-end funnel analysis using advanced SQL techniques including CTEs, conditional aggregation, NULLIF for safe division, DATEDIFF for time calculations, and UNION ALL for vertical result formatting. The queries are production-ready and applicable to any BI or analytics reporting environment.
